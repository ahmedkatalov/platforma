# DevOps Platform — платформа обучения

Go (chi + pgx + PostgreSQL) на бэкенде, React 19 + TypeScript + Tailwind v4 на фронтенде.
Отдельный проект со своей базой — ни с чем другим не связан.

## Что уже работает

- **Аккаунты и доступы.** JWT (access + refresh), роли `admin` / `student`, статусы
  `invited` / `active` / `blocked`, блокировка закрывает все сессии.
- **Админ создаётся из терминала** командой `createadmin`.
- **Админ заводит студентов**: генерируется временный пароль, доступы уходят на почту.
- **Самостоятельная регистрация** — только с подтверждением реальной почты кодом (EmailJS).
- **Восстановление пароля** кодом на почту.
- **Курсы**: курс → модули → уроки четырёх типов (`text`, `quiz`, `terminal`, `code`),
  публикация, назначение студентам.
- **Статистика**: дни посещения, серия дней подряд, время на платформе, прогресс по урокам —
  у студента свой кабинет, у админа сводка по всем.
- **Журнал действий** администратора.
- **Прохождение уроков**: теория в Markdown, квизы с проверкой на сервере, тренажёр терминала
  и практика с кодом. Правильные ответы студенту не отдаются — проверка только на бэкенде.
- **Тренажёр терминала** — учебный эмулятор командной строки с виртуальной файловой системой.
  Понимает работу с файлами (`ls`, `cd`, `cat`, `grep`, `find`, `chmod`, `sort`, `wc`),
  систему (`ps`, `df`, `free`, `systemctl`, `journalctl`), сеть (`curl`, `dig`, `ss`, `ping`, `nginx`),
  `git`, `docker`, `kubectl`, `helm`, `terraform`, `ansible`, `openssl` и `ssh-keygen`,
  конвейеры через `|` и историю по стрелкам. Задания проверяются по эталонным командам на сервере.
- **Практика с кодом** — редактор с номерами строк и автоотступом (важно для YAML),
  проверки решения задаются админом (`содержит` / `не содержит` / регулярное выражение).
- **Статистика квизов**: средний балл, точность ответов, скорость ответа на вопрос,
  история всех попыток — у студента и в карточке студента у админа.
- **Конструкторы содержимого** в админке: визуальные редакторы квиза, заданий терминала
  и практики с кодом, с переключением на «сырой» JSON.
- **Курс по DevOps** из 11 модулей и 42 уроков (~12 часов): введение, Linux, Git, сети и nginx,
  Docker, CI/CD, инфраструктура как код, Kubernetes, мониторинг, безопасность и итоговая
  аттестация. В каждом модуле теория, тренажёр терминала, практика с конфигурацией и квиз.
- **Сертификаты**: выдаются автоматически при прохождении всех уроков курса, у каждого
  уникальный номер и публичная страница проверки — ссылку можно отправить работодателю.
  Админ видит все сертификаты и может отозвать любой.
- **Сроки прохождения**: админ задаёт дедлайн для студента, платформа сама напоминает письмом
  за три дня, за день, в день дедлайна и после просрочки, а также если студент неделю не заходил.
- **Экспорт отчётов** в CSV: успеваемость студентов и реестр сертификатов (открывается в Excel).
- **Картинки в уроках**: библиотека загруженных файлов с вставкой в текст одним кликом.
- **Оформление**: светлая и тёмная темы, пресеты акцентов и тонов, настройка скруглений,
  «стекла», подсветки фона, масштаба шрифта, контраста и плотности. Пользователь настраивает
  под себя, админ может применить своё оформление для всей платформы.

## Курс по DevOps

Готовый курс для начинающих: 11 модулей, 72 урока, около 15 часов.
Предварительных знаний не требуется — начинаем с первых команд в терминале.

| # | Модуль | Темы |
|---|---|---|
| 1 | Знакомство с DevOps | что это простыми словами, словарь терминов, как учиться |
| 2 | Linux и командная строка | терминал, права доступа, процессы и логи, скрипт диагностики |
| 3 | Git и командная работа | коммиты и индекс, ветки и pull request, .gitignore |
| 4 | Сети и веб-сервер | путь запроса и коды ответов, HTTPS и сертификаты, nginx |
| 5 | Docker и контейнеры | зачем контейнеры, Dockerfile и слои, Compose |
| 6 | CI/CD | конвейер и окружения, GitOps, GitHub Actions |
| 7 | Инфраструктура как код | Terraform и состояние, Ansible и плейбуки |
| 8 | Kubernetes | объекты кластера, обновления и пробы, ConfigMap и Secret |
| 9 | Мониторинг и логи | метрики против логов, OpenTelemetry, SLO и дежурство |
| 10 | Безопасность и секреты | пароли и доступы, безопасные образы, цепочка поставки |
| 11 | Итоговая аттестация | экзамен, диагностика инцидента, манифест для прода |

Состав: 24 урока теории, **27 квизов**, 11 тренажёров терминала, 10 практик с конфигурациями.

Как устроено обучение:

- каждая тема заканчивается своим квизом, а не один квиз на весь модуль;
- в 22 квизах есть вопрос на повторение прошлых тем — помечен значком «повторение»;
- 167 вопросов, у каждого разбор ответа после проверки;
- отдельная страница «Квизы» в кабинете: прогресс, фильтры «не пройдены» и «стоит повторить»;
- заметки: студент выделяет текст в уроке и сохраняет цитату кнопкой «В заметки»;
  на странице «Заметки» видно, из какого модуля и урока цитата, со ссылкой и своим комментарием;
- в уроках: оглавление «В этом уроке», кнопка копирования у блоков кода, узкая колонка текста;
- каждый урок теории: «Зачем это нужно» → объяснение с аналогией → пример →
  «Частые ошибки новичка» → три пункта «Запомнить»;
- средняя длина предложения 49 знаков, термины объясняются при первом появлении;
- под каждым уроком блок «Материалы по теме» — 122 ссылки на официальную документацию.

Содержание актуально на 2026 год: OpenTofu, Gateway API, Compose v2, GitOps,
OpenTelemetry, OIDC вместо долгоживущих секретов, SBOM и подпись образов.

Загрузка курса в базу:

```bash
cd backend && go run ./cmd/seedcourse -force
```

Проверка качества курса:

```bash
cd backend && go run ./cmd/checkcourse
```

Утилита проверяет, что эталонные ответы квизов проходят порог, команды тренажёров
засчитываются, решения практик проходят все проверки, у каждого урока есть материалы
и подсказки, а предложения не длиннее 160 знаков.


## Запуск

### 1. База данных

```bash
docker compose up -d db
```

Поднимет PostgreSQL 16 на `127.0.0.1:5433` (база `platforma`, пользователь `platforma`).

### 2. Бэкенд

```bash
cd backend && cp .env.example .env
```

В `.env` обязательно задайте `JWT_SECRET` (не короче 32 символов):

```bash
openssl rand -hex 32
```

Запуск (миграции применяются автоматически при старте):

```bash
cd backend && go run ./cmd/api
```

API поднимется на http://localhost:8090.

### 3. Администратор

```bash
cd backend && go run ./cmd/createadmin
```

Команда спросит почту, имя и пароль. Неинтерактивно:

```bash
cd backend && go run ./cmd/createadmin -email admin@example.com -name "Ахмед" -password "Secret123"
```

Флаг `-force` обновит существующий аккаунт до администратора и сменит пароль.

### 4. Курс по DevOps

```bash
cd backend && go run ./cmd/seedcourse
```

Загрузит курс «DevOps с нуля до практики»: 11 модулей, 42 урока, около 12 часов.
Флаг `-force` пересоздаёт курс, `-publish=false` оставляет его черновиком.
После загрузки назначьте курс студентам в разделе «Студенты».

Проверить целостность курса после правок контента:

```bash
cd backend && go run ./cmd/checkcourse
```

Команда убеждается, что у каждого вопроса есть верный ответ и пояснение,
у каждого задания терминала — эталонная команда с подсказкой,
а эталонное решение практики проходит все проверки задания.

### 5. Фронтенд

```bash
cd frontend && npm install && npm run dev
```

Откроется http://localhost:5173, запросы `/api` проксируются на бэкенд.

## Почта (EmailJS)

Коды подтверждения и письма с доступами уходят через EmailJS — так же, как в проекте cmf.
Заполните в `backend/.env`:

```
EMAILJS_SERVICE_ID=
EMAILJS_TEMPLATE_ID=
EMAILJS_PUBLIC_KEY=
EMAILJS_PRIVATE_KEY=
```

Переменные шаблона: `to_email`, `email`, `to_name`, `code`, `passcode`, `subject`, `message`, `link`.
Пока ключи не заданы, письма не отправляются, а код подтверждения печатается в лог сервера —
удобно для локальной разработки.

## Структура

```
backend/
  cmd/api            — HTTP-сервер
  cmd/createadmin    — создание администратора из терминала
  cmd/seedcourse     — загрузка курса по DevOps
  cmd/checkcourse    — проверка курса на решаемость и полноту
  internal/auth      — JWT, пароли, одноразовые коды
  internal/config    — конфигурация из окружения
  internal/db        — пул соединений и миграции (embed)
  internal/domain    — модели, разбор и проверка содержимого уроков
  internal/handler   — HTTP-обработчики
  internal/jobs      — фоновые задачи: напоминания о сроках
  internal/mailer    — отправка писем через EmailJS
  internal/middleware— авторизация и проверка роли
  internal/repository— доступ к данным
  internal/router    — дерево маршрутов
  internal/seed      — содержимое курса по DevOps (модуль на файл)
  internal/service   — бизнес-логика (auth, пользователи)

frontend/src/
  app                — store, роутинг
  features/auth      — вход, регистрация, восстановление
  features/admin     — обзор, студенты, курсы, оформление, журнал
  features/student   — кабинет, курсы, статистика, профиль
  features/learning  — плеер уроков: теория, квиз, терминал, код
                       lib/shell.ts и lib/shellTools.ts — учебный эмулятор терминала
  features/certificates — сертификаты и библиотека картинок
  shared/theme       — тема: настройки, палитра, CSS-переменные
  shared/ui          — UI-кит и уведомления
  widgets            — каркас приложения
```
