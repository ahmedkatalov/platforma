## Что сделано

- Модуль из **8 уроков** (6 text + 1 code + 1 quiz). Курс: 276 → 284 урока, 20 → 21 модуль, ~56 ч.
- Сквозная идея: ИИ УСИЛИВАЕТ, но не заменяет; каждый сгенерированный артефакт проверяется линтером и глазами; правило «гипотеза от ИИ → проверка командой → правка».
- Практика (dockerfile): «плохой» Dockerfile «от ИИ» (python:latest, root, apt без очистки, COPY . . до зависимостей) → студент чинит; checks в духе hadolint (notContains :latest, USER, --no-install-recommends, rm -rf apt lists, порядок COPY).
- Каждый текстовый урок — с «## Домашнее задание».
